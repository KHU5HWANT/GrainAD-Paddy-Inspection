=======================

PRESENT

RUN
Use RUN_DEMO.cmd after SETUP_WINDOWS.cmd on a new laptop.
On the training laptop, run:
.venv312\Scripts\python.exe scripts\demo_grainad.py

MODEL
Current demo averages the top 5% of patches using cutoff -3.505190372467041.
Retrospective audit: AUROC 94.40%, accuracy 85.80%, recall 88.70%,
healthy false alarms 17.10%. Fresh external validation remains necessary.

GITHUB CODE EDITION
This repository excludes trained weights, full datasets and virtual environments.
For inference, obtain the three weight files from the owner's portable package:
results/paddy_full/ica/models/ica.pth
results/paddy_full/grainad/models/grain/ckpt.pth
datasets/torch-cache/hub/checkpoints/wide_resnet50_2-95faca4d.pth
Place them at these paths before running the demo.
